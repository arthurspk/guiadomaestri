# 📨 Biblioteca de prompts

> Prompts prontos para o **Compositor de Prompts** do Maestri (`Ctrl⇧P`) — copie, ajuste o
> que estiver entre `< >`, e cole no terminal certo.

## Prompts

- **[Criar uma partitura nova](./criar-partitura.md)** — faz o maestro montar um time e um
  contrato para o seu objetivo, seguindo os princípios do guia. Cole no maestro (fable).
- **[Validar o Discord do Maestri](./validar-discord-maestri.md)** — faz um Claude com
  acesso ao Discord percorrer o servidor, validar as informações deste guia e coletar o que
  falta. Somente leitura.

## Como contribuir um prompt

1. Adicione um `.md` com: para que serve, em qual terminal colar, e o bloco do prompt num
   fenced code block ```text.
2. Deixe claros os placeholders `< >` e quaisquer pré-requisitos (portal conectado, nota
   existente, papel do terminal).
3. Linke a partir deste índice.

Veja também as [receitas de rotinas](../receitas/rotinas.md) (prompts agendados) e a
[biblioteca de responsabilidades](../roles/CATALOGO.md) (prompts de papel para `role.json`).
