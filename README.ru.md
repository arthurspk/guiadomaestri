## 🎯 Что это

> **Maestri** — приложение для macOS, где вы **дирижируете командой кодовых агентов** — Claude Code, Codex, Gemini, OpenCode — на **бесконечном холсте**: терминалы — это агенты, markdown-заметки — общий источник истины, порталы — встроенные браузеры для живой проверки, а **маэстро** делегирует и координирует. Этот репозиторий одновременно **руководство** и **генератор на Python**, создающий **257 партитур** (`.maestripartitura`), готовых к перетаскиванию на холст и дирижированию — каждая партитура это целая команда со встроенными ролями, заметками, порталами и связями. Акцент на **технологии**, плюс 11 бизнес-областей (дизайн, продукт, маркетинг, продажи, данные, безопасность, финансы, юриспруденция, поддержка, управление проектами, исследования).

## 💡 Как устроено это руководство

> Два влияния вместе. **Деление по областям** (отделы ИИ-агентства) взято из [agency-agents](https://github.com/msitarzewski/agency-agents) — каталога из 230+ агентов в 18 отделах. **Оформление** — шапка, вступление, оглавление с якорями и разделы — следует [guiadevbrasil](https://github.com/arthurspk/guiadevbrasil). Подробности сравнения в [docs/07](docs/07-areas-e-agentes.md).

## ⚡ Maestri каждый день

> Партитуры — это начало; ценность в процессе. [Руководство на каждый день](docs/06-maestri-no-dia-a-dia.md) показывает, как использовать возможности Maestri в реальных ситуациях, а документы [08](docs/08-andares-e-partituras.md) и [09](docs/09-portais-mobile-web-emulador.md) углубляются в этажи и порталы.

- **🏢 Этажи (Floors)** — изолированные копии репозитория со своей веткой: работайте на нескольких фронтах параллельно без `git stash`, с хуками Setup/Run/Teardown. Совместите с партитурой, чтобы поднять целую команду, изолированную на ветке.
- **🌐 Порталы** — живая проверка в браузере, мобильном вебе и на **устройстве** (симулятор iOS / эмулятор Android / физическое устройство): доказать баг, принять фичу, проверить лендинг, протестировать нативное приложение.
- **📝 Заметки** — источник истины, переживающий сессию; перенесите в репозиторий то, что должно быть в git, свяжите в интеллект-карту, дайте Ombro сделать сводку.
- **⏰ Рутины** — повторяющаяся работа сама по себе: страж CI, наблюдатель деплоя, клиппинг конкурентов, ежедневное закрытие, триаж тикетов.
- **👤 Ombro** — локальный второй пилот внимания: «что делали агенты, пока меня не было?».

## 🤖 Политика моделей

> Fable дирижирует, Opus исполняет, Codex/Gemini оспаривают.

- **🎼 Оркестрация** (маэстро, conductor, IC, судья, lead) — `claude --dangerously-skip-permissions --model fable`.
- **🔨 Исполнение** (архитектор, билдеры, специалисты) — `--model opus`.
- **🛡️ Состязательное ревью** (релиз, wardens, дуэль) — `codex` / `gemini`, намеренно: другая модель ловит то, что упустила первая.
- Подробности и предохранители в [docs/05](docs/05-modelos-e-seguranca.md).

## 🛠️ Перегенерация и проверка

> Генератору не нужно ничего, кроме стандартной библиотеки Python 3. Детерминированные UUID: перегенерация даёт побайтово идентичные файлы.

```bash
python3 scripts/generate_partituras.py     # → "Gerados 257 templates em 12 áreas"
python3 scripts/generate_hub.py            # → roles/ + notas/ + instrucoes/
python3 tests/validate_partituras.py        # → "Zero divergências" по сравнению с официальной партитурой
python3 tests/validate_hub.py               # → проверяет файлы role.json и структуру хаба
```

- `scripts/maestri_build.py` — класс `Partitura`, сериализация, ropePoints, лейаут.
- `scripts/roles_lib.py` — промпты ролей (pt-BR) + шаблоны заметок.
- `scripts/generate_partituras.py` — семейства, параметризованные каталогами, сгруппированные по областям.
- `tests/validate_partituras.py` — сравнивает ключи top/payload/узла/роли с официальным файлом.

## ⚠️ Безопасность

> Добавление партитуры на холст **запускает её терминалы и выполняет команды на вашей машине** (`claude`, `codex`, `gemini`).

- **Прочитайте команды** на экране проверки перед импортом и принимайте партитуры только из доверенных источников.
- Партитуры **Red Team** и любые наступательные операции работают **строго в авторизованном периметре**, никогда в проде и никогда с данными реальных людей.
- Подробности в [docs/05](docs/05-modelos-e-seguranca.md).
