# 📝 Templates de nota

> Notas markdown prontas para o Maestri: contrato, workboard, playbook de release, stack-checklist de 30 camadas, case-file de depuração, timeline de incidente, regras de engajamento de red team e o par briefing/board/findings das áreas de negócio.

## Como importar

- **Arraste** um arquivo `.md` deste diretório para o canvas do Maestri: ele vira uma nota apontando para o arquivo (fica no local original).
- Ou copie o conteúdo para uma nota gerenciada nova (`Ctrl⇧D`).
- Conecte a nota aos terminais que devem lê-la e escrevê-la.
